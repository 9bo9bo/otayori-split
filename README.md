# お便り分割

保育園・学校のお便りなどで届く **A3 / B4 PDF** を、家庭用プリンターで印刷できる **A4×2 / B5×2** に中央分割するWebツールです。

- 処理はすべてブラウザ内（ファイルはサーバーに送られません）
- iPhone Safari 対応、ホーム画面追加でオフライン利用可
- iOSショートカットから起動できます

## 分割ルール

| 入力 | 出力 | 切り方 |
|------|------|--------|
| A3（ヨコ） | A4×2 | 左右 |
| A3（タテ） | A4×2 | 上下 |
| B4（ヨコ・JIS） | B5×2 | 左右 |
| B4（タテ・JIS） | B5×2 | 上下 |

標準サイズ以外でも「中央で半分」に分割します。文字や図は画像化せず、PDFのまま切り出すため印刷品質を保ちやすいです。

## 使い方（iPhone）

1. Safari でこのアプリを開く
2. 共有ボタン → **ホーム画面に追加**
3. PDFを選ぶ → **分割する** → **共有・保存**
4. 印刷時は **実際のサイズ / 100%** を選ぶ（「用紙に合わせる」だと小さくなります）
5. 2枚を並べて貼り合わせると元の大きさになります

## iOSショートカット例

1. 「ショートカット」アプリで新規作成
2. 入力を **ファイル**（PDF）にする（共有シート用）
3. アクション **URLを開く** で、このアプリのURLを指定
4. 名前を「お便り分割」にして、共有シートに表示

使い方: お便りのPDFを共有 → 「お便り分割」→ アプリが開いたら同じPDFを選択して分割。

> iOSの制約上、ショートカットからWebアプリへPDFを直接渡せないため、起動後にファイル選択が必要です。

## 開発

```bash
npm install
npm run dev
npm run build
npm run preview
npm test
```

`dist/` を任意の静的ホスティング（GitHub Pages など）に置けます。`base: './'` のためサブディレクトリ配置にも対応しています。
